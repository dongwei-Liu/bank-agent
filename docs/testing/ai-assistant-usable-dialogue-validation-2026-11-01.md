每条提示词均由测试程序通过真实持久化 Agent 链路单独提交：创建本人会话 → 消息入队 → Agent Worker 调用已配置的 DeepSeek 模型 → LangGraph 选择受限业务 Tool → 轮询 Run 至终态 → 重新读取会话、AI 回复和结构化事件。中端和 Fineract 使用本机真实演示环境；此处“真实链路”不等于“React 前端手工输入”。

本轮没有在 Action 页面点击确认，没有提交 OTP，没有启动资金执行 Worker，也没有执行普通转账、卡片状态变更、定存申购/赎回或生日任务资金节点。办卡、转账和生日等写意图最多只生成待确认请求。精确余额、账户尾号、卡片尾号和内部引用在本文中脱敏；当时生成的未脱敏 `.runtime/demo-prompt-results-*.json` 已在 2026-11-01 工作区安全清理中删除，版本库仅保留本脱敏报告和可重复测试代码。
