# 成员 A Agent 任务拆分与验收记录

本文记录账户、支付、普通借记卡、定时转账和 AA 收款的 Agent 纵向切片。全局状态以 `master-plan.md` 为准；普通 Web App 和中端业务基座仍以 `frontend-backend-requirements.md` 为准。

状态含义：`已自动验收` 表示代码和受控自动化通过；`待真实验收` 表示不得把创建 Action/草稿等同于真实资金或卡片状态已经改变。

## 真实验收边界

创建 Action、保存计划或创建 AA 请求只证明请求被中端安全持久化，不代表资金已经转出、卡片已经激活或计划已经执行。真实验收必须在隔离 Demo 数据上依次检查 Action 确认、OTP、执行/核对状态、Fineract 双边余额和流水、中端审计记录及幂等重放。
